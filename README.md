# Introduction to the targeted orthologs search using fDOG

This tutorial is a 30 mins intro into the generation of phylogenetic profiles using a targeted ortholog search. It combines the search for two plant cell wall degrading enzymes in ca. 100 gene sets as well as in one unannotated genome assemblies. 

![workflow](docs/figures/fdog_workflow.jpg)

**Figure 1: Workflow of fDOG.** Taken from [Tran et al. 2025](https://pmc.ncbi.nlm.nih.gov/articles/PMC12198962/).

## Software Requirements

* Jupyter Notebook
* running instances of fDOG and PhyloProfile

## How to follow this Tutorial

Open the `cellulase_comparison.ipynb` notebook in this directory using Jupyter. It will take you through all steps of this tutorial.
